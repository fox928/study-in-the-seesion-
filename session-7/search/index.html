شرح دوال البحث والتصفية في JavaScript

1. دالة search

تُستخدم للبحث داخل النصوص. ترجع موقع الكلمة إذا وُجدت، أو -1 إذا لم تُوجد. 


const text = "أنا أحب التفاح";
console.log(text.search("تفاح")); // 8

2. دالة filter()

تُستخدم لتصفية عناصر المصفوفة بناءً على شرط معين. 


const nums = [1, 2, 3, 4];
const even = nums.filter(n => n % 2 === 0);
console.log(even); // [2, 4]

3. دالة reduce()

تُستخدم لتجميع البيانات داخل المصفوفة إلى قيمة واحدة. 


const nums = [10, 20, 30];
const sum = nums.reduce((acc, val) => acc + val, 0);
console.log(sum); // 60

4. دالة findIndex()

تُستخدم لإيجاد أول عنصر يحقق شرط معين، وترجع فهرسه. 


const ages = [18, 20, 25];
const index = ages.findIndex(age => age > 20);
console.log(index); // 2

5. دالة lastIndexOf()

تُستخدم لإيجاد آخر موقع لعنصر معين في المصفوفة. 


const colors = ["red", "blue", "green", "blue"];
const index = colors.lastIndexOf("blue");
console.log(index); // 3
